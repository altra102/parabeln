# Parabeln verstehen

Lernseite zu quadratischen Funktionen (Realschule NRW, Jahrgang 9): kurze Erklärvideos in Schleife, Übungsaufgaben mit Rückmeldung im Kästchenheft-Look und ein 3D-Parcours zum Üben.

**Live:** https://altra102.github.io/parabeln/

Alles steckt in einer Datei (`parabeln.html`) und funktioniert auch offline. Der Fortschritt wird nur im Browser gespeichert (localStorage).
